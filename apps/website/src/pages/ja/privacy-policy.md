このポリシーは、OpenCI株式会社（以下「当社」）がウェブサイト、ダッシュボード、CI/CD サービスの提供にあたって取り扱う個人情報に適用されます。

## アカウントと Google ログイン

「**Google で続行**」を選ぶと、Google からアカウントの識別子、メールアドレス、および氏名・プロフィール画像など提供可能な基本プロフィールを受け取ります。当社はこれらを OpenCI Cloud のアカウント情報として Firebase Authentication に保存し、ログイン認証、操作とアカウントの関連付け、所属チームでのメンバー表示に利用します。同じチームのメンバーは、メンバー一覧で氏名、メールアドレス、プロフィール画像を確認できます。

## リポジトリ、ビルド、外部連携

リポジトリを接続すると、当社はリポジトリやコミットの識別子、ソースコード、ワークフロー設定、利用を許可された認証情報を処理します。これらは依頼されたビルド、テスト、配布を実行するために使います。ビルド結果とログはチームのメンバーが閲覧できます。ワークフローの設定に応じ、ビルドの状態、成果物、リリース情報が GitHub やアプリ配布サービスなど、チームが選んだ送信先に共有されることがあります。

当社はチームデータへのアクセスを権限に応じて制限し、OpenCI Cloud のシークレットとして登録された認証情報を専用のシークレット管理サービスに保管します。利用者自身の Firebase プロジェクトやランナーを接続した場合、その環境で処理する情報へのアクセスは当該環境の運用者が管理します。

## 利用記録、障害調査、お問い合わせ

当社はビルド時間、ジョブの結果、利用記録を、ランナーの運用、料金計算、障害調査に使います。また、セキュリティの確保と安定性の改善のために、IP アドレス、端末・ブラウザーの情報や診断データを取得することがあります。ダッシュボードの診断機能が有効な場合、Sentry にクラッシュレポート、性能情報、スクリーンショット、操作内容を再現するセッションリプレイが送られることがあります。これらには画面に表示された情報が含まれる場合があります。

ウェブサイトとダッシュボードは、ログイン状態の維持や言語・表示設定の保存に、ブラウザーのストレージや Cookie を使用します。これらはブラウザーの設定から管理できます。お問い合わせ時にいただいた情報は、回答と、アカウントやサービスの運営に関する連絡に利用します。

## 決済

Web 決済で入力する支払い情報は Stripe が取得します。当社は、顧客や決済手段の識別子、請求書、支払い状況、チームの利用量を、請求、お問い合わせ対応、会計記録のために取り扱います。App Store での購入は Apple が決済します。アプリ内購入に RevenueCat を利用する場合は、OpenCI のアカウント識別子と購入・契約状況を使って購入済みの機能を有効にします。

## 情報の共有と保管

当社は個人情報を販売しません。このポリシーで説明した機能に必要な範囲で委託先に情報を共有し、チームメンバーには権限に応じて、外部連携先には利用者の設定に従って情報を提供します。このほか、法令に基づく場合、利用者その他の方の権利や安全を守る必要がある場合、合併・買収・事業譲渡の場合には、適用法令に従って情報を開示することがあります。

当社は、サービスの提供、会計処理、紛争対応、法令上の義務の履行などに必要な期間、情報を保管します。ログイン用アカウントはダッシュボードの設定で削除できます。削除後も、チームが共有するビルド記録や請求書は、これらの目的に必要な範囲で保管します。

## 利用者の権利と窓口

適用される法令に応じて、ご自身の情報の開示、訂正、削除、利用停止、データの移転、取り扱いへの異議申し立て、同意の撤回を求めることができます。こうした請求や安全管理措置に関するお問い合わせは [support@openci.org](mailto:support@openci.org) で受け付けます。対応にあたり、ご本人確認に必要な情報を伺うことがあります。

運営者は OpenCI株式会社、代表者は青木正浩です。所在地は[会社情報ページ](/studio/)でご確認いただけます。

このポリシーを変更する場合は、このページに掲載し、最終更新日を更新します。サービスの利用条件は[利用規約](/ja/terms-of-service/)をご覧ください。
