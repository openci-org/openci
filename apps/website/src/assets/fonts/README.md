# Noto Sans JP

`NotoSansJP.ttf` is an unmodified copy of Google Fonts' variable
[`NotoSansJP[wght].ttf`](https://github.com/google/fonts/blob/main/ofl/notosansjp/NotoSansJP%5Bwght%5D.ttf).
It includes Japanese and Latin glyphs and is used only while generating social images.
