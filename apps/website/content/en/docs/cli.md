## Install

Install the CLI with Dart 3.11.5 or later.

```sh
dart install genuineci_cli
genuineci --help
```

If the command is not found, check the [Dart PATH configuration](https://dart.dev/tools/dart-install).

## Log in

Use the same email address and password as the dashboard. Enter your password in the interactive prompt.

```sh
genuineci login
```

To use another server, specify its HTTPS URL.

```sh
genuineci login --server https://ci.example.com
```

For a self-hosted Firebase project, also provide its Web API key with `--firebase-api-key`.

## Check your status

View your current profile, server, and team.

```sh
genuineci status
```

## Switch teams

Select a team interactively. Use the arrow keys to move, Enter to select, and Esc to cancel.

```sh
genuineci switch team
```

Secret commands will then operate on the newly selected team.

## Commands

| Command | Purpose |
| --- | --- |
| `genuineci login` | Log in to a remote environment |
| `genuineci status` | Check your current profile and team |
| `genuineci switch team` | Switch the active team |
| `genuineci list secrets` | List secret names |
| `genuineci register secret` | Register or update a secret |
| `genuineci register secretFile` | Register a file as Base64 |
| `genuineci sync` | Generate secret definitions and workspace paths |
| `genuineci sync --secrets` | Generate secret definitions only |
| `genuineci sync --paths` | Generate workspace paths only; no login required |
| `genuineci update` | Update the CLI |

Files generated by `sync` are saved under `openci/generated/`. Import `generated/secrets.g.dart` and `generated/paths.g.dart` in your workflows.

## Language and updates

Switch CLI messages between Japanese and English.

```sh
genuineci use japanese
genuineci use english
```

To update to the latest stable release, run:

```sh
genuineci update
```
