# OpenCI ダッシュボード デザインガイドライン (DESIGN.md)

OpenCIは、「毎日使う、よい・正しいツール」として、実用性と心地よさを最優先事項としています。無理にプレミアム感を演出するのではなく、モバイル・デスクトップの双方で使いやすく、日々の運用に馴染むシンプルで正しいUI/UXを目指します。

独自のデザイン言語を構築するのではなく、**Material Design 3 (M3) の原則にできるだけ準拠します。** また、Flutterの標準ウィジェットをうまく活用・応用できるデザインを最優先し、開発効率とUIの一貫性を両立させます。
